# VOLTRIX ⚡

Бесплатная первая версия сервиса подбора комплектующих и сборки ПК на русском языке. Один процесс FastAPI обслуживает адаптивный сайт, API и Telegram-бота на aiogram 3 через webhook. Платных AI API, баз данных и внешних шрифтов нет.

## Возможности

- Главная, конфигуратор, каталог восьми категорий, сравнение 2–4 моделей, умный подбор, сохранённые сборки, страница о проекте.
- Проверки сокета и поддержки CPU, типов/объёма/числа модулей RAM, форм-фактора платы, длины и толщины GPU, высоты/крепления/теплового запаса кулера, мощности/разъёмов/размеров БП, NVMe и наличия графики.
- Подбор по бюджету 15 000–500 000 ₽, назначению и предпочтениям AMD/Intel/NVIDIA.
- Реальные модели; **все встроенные цены — примерные расчётные значения, не актуальные предложения**. Автоматического сбора цен и наличия нет. В карточке можно вручную сравнить три найденные цены магазинов и применить минимальную к расчёту. Эти записи также сохраняются в браузере. Карточки открывают поиск модели у трёх продавцов. Сравнение реальных предложений выполняет пользователь на их сайтах; найденные цены можно ввести в конфигураторе, и алгоритм использует их.
- Черновик, цены и до 50 сборок в localStorage; экспорт/импорт JSON до 200 КБ, ссылки на состав (без введённых цен).
- Анимации с поддержкой `prefers-reduced-motion`, мобильное меню, клавиатурная навигация и доступные диалоги.
- Обработка сетевых ошибок, валидация входа, ограничение тела POST 64 КБ, секрет webhook, ограниченная дедупликация обновлений.

## Локальный запуск

Python 3.12, команды из корня проекта:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
cp .env.example .env
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

В Windows скопируйте `.env.example` в `.env` через проводник или `Copy-Item`. Откройте <http://127.0.0.1:8000>. API: `/docs`, состояние: `/health`. Без Telegram-токена сайт полностью работает. SQLite не требуется даже локально; сервер не сохраняет пользовательские данные. Если позже понадобится БД, SQLite допустим только для локальной разработки.

## Один бесплатный Render Web Service

1. Загрузите файлы из этой папки в корень GitHub-репозитория. Если репозиторий ещё не настроен:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial VOLTRIX implementation"
   git remote add origin https://github.com/YOUR_LOGIN/voltrix.git
   git push -u origin main
   ```
   В подготовленном рабочем каталоге Git может уже быть инициализирован. Перед публикацией проверьте `git status` и наличие `.gitignore`. `.env` и `.venv` не загружайте.
2. В Render выберите **New → Blueprint**, подключите репозиторий. `render.yaml` создаёт один Python Web Service с `plan: free`, без базы и диска. Вставьте токен бота в `TELEGRAM_BOT_TOKEN`; для сайта без бота оставьте пустым. Доступность бесплатного тарифа определяется вашим аккаунтом и текущими условиями Render.
3. Render генерирует `TELEGRAM_WEBHOOK_SECRET`. Публичный адрес автоматически берётся из `RENDER_EXTERNAL_URL`. Если используете собственный домен, задайте `PUBLIC_BASE_URL=https://ваш-домен` (корень сайта, без пути).
4. Build: `pip install -r requirements.txt`. Start:
   ```text
   uvicorn app.main:app --host 0.0.0.0 --port $PORT --workers 1
   ```
   Health check: `/health`. Используйте **ровно один worker**: дедупликация, ограничение параллельного подбора и бот работают в памяти одного процесса.
5. После первого старта откройте сайт и `/health`. `status: ok` означает готовность сайта. При настроенном боте `telegram_configured: true`, а после регистрации — `telegram_registered: true`. Если регистрация временно не удалась, приложение повторяет её через 5, 10, 20, 40, затем 60 секунд; сайт при этом доступен.

Можно создать сервис вручную: Python runtime, Free instance, команды выше; задайте те же переменные и сгенерируйте секрет вручную:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Секрет: 32–256 символов `A–Z a–z 0–9 _ -`. Токен и секрет не публикуйте и не добавляйте в URL. `PUBLIC_BASE_URL` имеет приоритет над `RENDER_EXTERNAL_URL`.

### Ограничения бесплатного Render

- Бесплатный сервис засыпает после бездействия. Первый HTTP-запрос или webhook может ждать около минуты. Это не круглосуточный SLA. На сайте есть таймаут 65 секунд и сообщение с предложением повторить запрос.
- Telegram может повторять доставку после пробуждения. Webhook остаётся зарегистрированным при остановке сервиса; приложение не вызывает `deleteWebhook` при завершении и не сбрасывает ожидающие обновления.
- Локальная файловая система ненадёжна: БД, пользовательские сборки и сессии на сервере не создаются. Каталог — часть Git-исходников. Сборки хранятся в браузере; очистка данных удалит их. Делайте экспорт JSON для резервной копии/переноса.
- Дедупликация Telegram хранит до 2000 успешных update_id в течение часа в памяти; рестарт очищает её. После рестарта или сбоя между отправкой ответа и отметкой об успехе возможны повторные ответы. Гарантии exactly-once без долговременного хранилища нет.
- Запрос подбора выполняется в отдельном потоке, по одному одновременно; бот и сайт используют общий модуль. Регистрация webhook выставляет `max_connections=1`. Для большого трафика потребуется пересмотреть инфраструктуру, но первая версия не требует платных сервисов.
- Не используются искусственные запросы для обхода сна или платные внешние базы.

## Telegram-бот

1. Создайте бота через `@BotFather` и получите токен.
2. Задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, публичный HTTPS-адрес сервиса (в Render автоматически).
3. Перезапустите/deploy сервис. Он сам вызовет `setWebhook` для `/telegram/webhook` с секретом и зарегистрирует команды. Polling не запускается.
4. Отправьте боту:
   ```text
   /start
   /build 80000 gaming AMD NVIDIA
   /build 110000 work any any
   /build 45000 office Intel any
   /build 80000 игры AMD NVIDIA
   /help
   ```

Задачи: `gaming`/`игры`, `work`/`работа`, `office`/`офис`. Бренды можно пропустить. Предпочтение бренда GPU требует дискретную карту; без предпочтения в офисном/рабочем подборе допустима встроенная графика. В игровой сборке всегда есть дискретная GPU. Бот отправляет состав, сумму, предупреждения и ссылку на конфигуратор. Веб-сайт и бот вызывают один `app.engine.recommend`; бот использует примерные цены каталога (введённые в браузере цены ему недоступны).

Для локального webhook нужен доступный Telegram HTTPS-адрес, направленный на локальный порт; обычный localhost Telegram недоступен. Один токен может иметь только один webhook: для локальной разработки используйте отдельного тестового бота. Реальный токен не нужен для автоматических тестов.

Если сайт работает, а бот молчит: проверьте `/health`, Render environment, HTTPS-адрес и сообщения `Telegram disabled`/`registration failed` в логах. Неправильная конфигурация отключает бота, но сохраняет доступность сайта. Telegram-секрет проверяется до разбора обновления; невалидное тело получает 400, ошибка обработчика — 503 для повтора.

## Алгоритм и честность данных

`app/data/catalog.json` — редактируемый стартовый каталог. Поля: `id`, `category`, `name`, `brand`, `estimate_rub`, `specs`; `metadata` содержит объявления о расчётных ценах и ссылках на производителей. `estimate_rub` — **не live-цена**, дата актуальности ей не приписывается. При добавлении моделей поддерживайте уникальные ID, единицы измерения и CPU Support List платы.

Подбор перебирает CPU + плату + RAM + GPU (либо iGPU для допустимых задач). Для каждой связки выбирает самый дешёвый совместимый кулер, корпус и БП, затем перебирает SSD. Берёт максимальную оценку для задачи при сумме не выше бюджета; равные оценки разрешаются меньшей ценой. Пользовательские цены заменяют расчётные только для переданных ID. Если бюджета не хватает, сообщает минимум с заданными предпочтениями.

Баллы CPU/GPU заданы редакционно, **не являются измерениями, FPS или гарантией производительности**. RAM даёт бонус до 32 ГБ, SSD — до 2 ТБ. Пусть C — балл CPU, G — GPU/iGPU, M = min(RAM,32)/16, S = min(SSD,2000)/1000:

- Игры: `0.30C + 0.65G + 4M + 2S - 0.15 × max(0, G - 1.8C)`.
- Работа: `0.65C + 0.20G + 12M + 5S`.
- Офис: `0.5 × min(C,65) + 0.1 × min(G,12) + 9M + 5S`.

Это оптимизация этой оценки по текущему каталогу, не универсальное доказательство лучшего ПК на рынке. Для конкретных игр, CUDA, видеомонтажа и другого ПО сверяйте требования самостоятельно. Периферия, ОС, сборка и доставка не входят в бюджет.

Мощность БП: `(CPU power + GPU power + 60 Вт) × 1.35`, округление вверх до 50 Вт. `power_w` и `thermal_budget_w` — консервативные проектные оценки VOLTRIX; тепловой запас кулера не выдаётся за паспортный TDP. Видеокарты указаны с конкретным исполнением производителя, поскольку размеры зависят от модели.

Проверка по каталогу не гарантирует фактическую совместимость всех ревизий: проверьте BIOS/CPU Support List, QVL и поддерживаемую частоту RAM, комплект LGA1700/AM5-креплений, перекрытие высоких модулей двухбашенным кулером, реальные кабели PCIe и влияние вентиляторов на зазоры корпуса. Эти ограничения показываются в интерфейсе.

## API

| Метод | Путь                | Назначение                                        |
| ----- | ------------------- | ------------------------------------------------- |
| GET   | `/api/catalog`      | Модели, категории, объявления, ссылки поиска      |
| POST  | `/api/build/check`  | Расчёт и проверки частичной/полной сборки         |
| POST  | `/api/recommend`    | Умный подбор                                      |
| POST  | `/api/compare`      | Характеристики 2–4 разных моделей одной категории |
| POST  | `/telegram/webhook` | aiogram update; обязательный секретный заголовок  |
| GET   | `/health`           | Готовность сайта и состояние регистрации бота     |

Пример подбора:

```json
{
  "budget": 80000,
  "purpose": "gaming",
  "cpu_brand": "any",
  "gpu_brand": "NVIDIA",
  "price_overrides": { "rtx4060": 31000 }
}
```

Пример частичной сборки:

```json
{
  "components": { "cpu": "r5600", "motherboard": "b550", "ram": "ddr4-16" },
  "price_overrides": { "r5600": 10000 }
}
```

Ошибки валидации возвращают 422. Цены — целые числа от 1 до 2 000 000 ₽, ID/категории должны существовать. Тело запроса не больше 64 КБ. Невозможный подбор возвращает 422 с объяснением.

## Проверки

```bash
pip install -r requirements-dev.txt
python -m pytest -q
node --check app/static/app.js
```

Тесты проверяют правила совместимости, ограничения бюджета и брендов, пользовательские цены, оптимальность на небольшом независимо перебранном каталоге, ошибки API, страницы, ограничение тела, webhook-секрет, повторы и общий алгоритм бота. GitHub Actions запускает pytest и проверку синтаксиса JS.

Дополнительная проверка настоящего браузера (не требуется для запуска сервиса):

```bash
pip install playwright==1.62.0
playwright install chromium
# В другом терминале запустите uvicorn, затем:
python tests/browser_smoke.py
```

Скрипт использует `/usr/bin/chromium`, если установлен; иначе Playwright Chromium. Проверяет desktop/mobile, отсутствие горизонтального переполнения, подбор, цены, сохранение, сравнение, карточки, меню и сообщение о малом бюджете. Скриншоты в `artifacts/` (игнорируются Git). Внешняя регистрация Telegram и фактический deploy Render требуют ваших токена и аккаунта и не выполняются этими тестами.

## Структура

```text
app/
  main.py           # FastAPI, lifespan, webhook, лимиты, страницы
  bot.py            # aiogram 3: команды, парсер, форматирование
  engine.py         # общий алгоритм и проверки
  schemas.py        # Pydantic-валидация
  catalog.py        # чтение каталога и ссылки поиска
  data/catalog.json
  static/           # русский интерфейс, CSS, JS, SVG
tests/              # unit/API и optional browser smoke
.github/workflows/tests.yml
requirements.txt / requirements-dev.txt
render.yaml / .env.example / .gitignore
```

Проект не требует Node.js для работы на Render: HTML/CSS/JS обслуживаются FastAPI без сборки.
