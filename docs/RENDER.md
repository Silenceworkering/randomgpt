# Бесплатный запуск: Render Free + Neon Free

Готовая конфигурация **не создаёт платных ресурсов**. Это спящий веб-сервис с webhook,
а не постоянно работающий worker. Постоянная база находится в Neon, без 30-дневного срока Render Free Postgres.

[Открыть бесплатное развёртывание Render](https://render.com/deploy?repo=https://github.com/Silenceworkering/randomgpt)

## 1. Создать бесплатную базу Neon

1. Откройте https://console.neon.tech/ и войдите через GitHub.
2. Оставьте тариф **Free**, создайте проект `dedlainych`, PostgreSQL 17, регион ближе к Frankfurt.
3. Откройте **Connect**, выключите **Connection pooling**, скопируйте обычную PostgreSQL connection string.
   Она содержит пароль — её нельзя публиковать или присылать в чат.
4. В конце URL оставьте `sslmode=require`. Если присутствует `&channel_binding=require`, удалите
   только этот параметр: используемый Python-драйвер asyncpg его не поддерживает. Остальное не меняйте.
   Приложение проверяет TLS-сертификат и имя сервера, небезопасный TLS не включается.

Формат: `postgresql://USER:PASSWORD@HOST/DATABASE?sslmode=require`.
Не вставляйте URL в файл репозитория — он вводится в защищённые настройки сервисов.

## 2. Подключить Render

1. Откройте кнопку развёртывания выше, войдите через GitHub, разрешите доступ к `Silenceworkering/randomgpt`.
2. Введите три значения:

   | Поле | Значение |
   |---|---|
   | `BOT_TOKEN` | Новый токен @Dedlainych_AI_bot из @BotFather |
   | `ADMIN_IDS` | Ваш числовой Telegram ID в квадратных скобках: `[123456789]` |
   | `DATABASE_URL` | Строка подключения Neon из первого шага |

3. Перед подтверждением проверьте: **один Web Service `dedlainych-free`, план Free, $0**, без Render Postgres.
   Если показывается платный worker или платная база, не подтверждайте: выберите ветку main и новый render.yaml.
4. Подтвердите **Deploy / Apply**. Дождитесь запуска и отправьте боту `/start`.

`WEBHOOK_SECRET` Render создаст автоматически; адрес сервиса он тоже передаст сам.
Порт, webhook в BotFather и базу Render настраивать вручную не нужно. Если кнопка не работает:
**New → Blueprint → randomgpt → main → render.yaml**.

Если вы ранее самостоятельно создали платные ресурсы по старой конфигурации, новый файл не отменяет
их оплату автоматически. Проверьте список ресурсов Render; сначала сохраните нужную БД, затем удалите
ненужные платные ресурсы. Самостоятельно агент платные сервисы не создавал.

## 3. Включить бесплатные уведомления — при необходимости

Бот отвечает на кнопки и принимает домашку без этого шага. Но спящий Render не может сам
гарантировать отправку сообщения в выбранное время. Поэтому рассылка вынесена в настоящее
плановое задание GitHub Actions, которое подключается к Neon напрямую и отправляет положенные сводки.
Оно **не пингует Render для обхода сна**.

В репозитории https://github.com/Silenceworkering/randomgpt:

1. **Settings → Secrets and variables → Actions → Secrets → New repository secret**:
   - `BOT_TOKEN` — тот же токен;
   - `DATABASE_URL` — тот же URL Neon;
   - `ADMIN_IDS` — тот же массив ID (необязательно, но нужен для восстановления админских сообщений в очереди).
2. На соседней вкладке **Variables** создайте `NOTIFICATIONS_ENABLED` со значением `true`.
3. Откройте **Actions → Бесплатная отправка сводок → Run workflow**, чтобы проверить подключение.

Задание запускается на стандартном Ubuntu runner примерно каждые 30 минут (:11 и :41 UTC).
Текущее время каждого студента учитывается: отправляется одна сводка после его выбранного времени.
Например, при времени 20:30 ближайшая проверка обычно 20:41, а не ровно 20:30.
GitHub может задерживать или пропускать плановые запуски. После 60 дней отсутствия активности
в публичном репозитории расписание может отключиться — включите его снова в Actions.
Никаких автоматических фиктивных коммитов для обхода этого ограничения нет.

GitHub Actions на стандартных runner бесплатен для публичного репозитория. Если сделаете репозиторий
приватным, отдельно проверьте бесплатный лимит Actions и бюджет; не включайте платные runner.
Не указывайте рабочую БД в TEST_DATABASE_URL — это переменная только для отдельной тестовой базы.

## Что будет работать

- Регистрация, меню, настройки, домашка, архив, выполнение и админка — по входящим webhook.
- Сбор новых сообщений разрешённых учебных чатов, OCR и документы — пока Render обрабатывает запросы.
- Расписание — после ручного импорта реальных занятий, фиктивных данных нет.
- Уведомления — после шага 3, с указанными ограничениями времени.
- Разбор заданий по умолчанию выполняется правилами; платных ИИ API нет.

Добавьте бота в учебный чат, отключите Group Privacy или выдайте подходящие права,
затем выполните в личном чате `/admin chat_add -100ВАШ_ID`.
Добавьте реальные предметы и расписание по инструкции README.

## Что означает «бесплатно» и какие ограничения

Условия проверены 14 октября 2026:

- **Render Free:** засыпает после 15 минут без входящих запросов. Первое сообщение после сна может
  ждать около минуты или дольше. Telegram повторяет webhook, если сервис ещё не проснулся.
  Есть месячные лимиты времени работы, трафика и сборок. Файлы контейнера временные.
  Тяжёлое OCR может превысить 512 МБ памяти; незавершённое событие остаётся в очереди.
- **Neon Free:** на текущем тарифе 1 ГБ на проект и 100 CU-hours вычислений в месяц, без карты и срока
  пробного периода. База засыпает после 5 минут без запросов. Выбирайте минимальный подходящий compute,
  следите за квотой. При активной группе лимита может не хватить — бесплатность не означает безлимитность.
- **GitHub Actions:** расписание не является точным будильником; возможны задержки и отключение по неактивности.

Оставляйте Free на всех сервисах. При исчерпании лимитов понадобится дождаться восстановления квоты
или уменьшить нагрузку; автоматического перехода на платный тариф код не выполняет.

Источники: [Render Free](https://render.com/docs/free), [Neon Free](https://neon.com/pricing),
[GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions),
[ограничения расписания](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule).

## Сохранность данных

Входящий webhook сохраняется в PostgreSQL до ответа Telegram. Повторный update_id не добавляется дважды;
обработку незавершённой очереди продолжает следующее обращение или плановое задание уведомлений.
После успешной обработки сырой JSON очищается, остаётся ID для защиты от повторов на 7 дней.
Необработанный JSON временно может содержать личные команды; он не выводится в логи и GitHub.
После пяти ошибок запись помечается failed и сырой JSON удаляется. Сообщение/команду может понадобиться повторить.

Очередь защищает от потери при сне/перезапуске, но не гарантирует exactly-once для внешних ответов Telegram:
при падении между отправкой ответа и фиксацией результата ответ может повториться.
Новые кнопки выполнения задают явный статус, поэтому повтор не снимает случайно галочку.
Если незавершённую фотографию восстанавливает GitHub runner без системного OCR, исходное вложение
сохраняется для проверки. Для штатного OCR в контейнере Render есть rus+eng.

Локальная PostgreSQL в Docker остаётся доступна для самостоятельного хостинга; в этом бесплатном варианте
используется Neon. Не храните постоянную базу на временном диске Render. Храните независимые копии БД:
на Neon Free окно восстановления ограничено (сейчас до 6 часов), для длительного хранения скачивайте
собственный pg_dump на защищённый носитель. Не публикуйте дампы в публичных Actions artifacts.

## Если не работает

- **Долго отвечает после перерыва:** это холодный старт Free, подождите. Не подключайте искусственные ping-сервисы.
- **Ошибка DATABASE_URL:** проверьте direct URL Neon, sslmode=require, отсутствие channel_binding=require,
  пароль и квоту Neon. Строку целиком в чат не присылайте.
- **Бот не получает сообщения:** выключите локальный polling-экземпляр с тем же токеном, проверьте Render Logs.
  Webhook устанавливается приложением при старте автоматически.
- **Нет уведомлений:** выполните шаг 3 и проверьте Actions; настройте часовой пояс и включите уведомления у студента.
- **Нет расписания/домашки:** импортируйте настоящие данные, проверьте подключённые чаты и очередь админской проверки.
- **Ресурс платный:** проверьте актуальный main и plan: free. Этот Blueprint не создаёт базы Render и worker.

Код и конфигурация подготовлены, но аккаунты Render/Neon и секреты не подключены автоматически.
Бот не считается запущенным до успешного реального /start.
