# HUMAN.EXE · 18+

«Ты родился. Уже хуёво. Дальше — хуже.»

Полностью браузерный абсурдный симулятор жизни на русском языке. React, TypeScript, Vite, Tailwind CSS, Zustand, IndexedDB и Vitest. Без сервера, аккаунта, платных API и внешних шрифтов. Взрослый юмор, мат, вымышленные политические ситуации.

## Запуск

```sh
cd human-exe
npm ci
npm run dev
```

`npm test` проверяет движок и хранилище, `npm run build` проверяет TypeScript и собирает `dist`. `npm run preview` запускает production-сборку.

## Как играть

Подтвердите возраст 18+ и начните новую жизнь. Выберите ответ на событие — жизнь продвинется во времени, доходы и расходы рассчитаются автоматически. После совершеннолетия доступны работа, обучение, отдых, знакомства, профессии, имущество и кредиты. После формирования взрослых романтических отношений доступна близость по взаимному согласию. Сцены не содержат графических описаний; семейные связи и несовершеннолетние исключены. Эти действия тоже занимают время: бесплатного бесконечного заработка нет. Требования и стоимость указаны на карточках. Решения записываются в хронику; некоторые возвращаются спустя годы. Игра заканчивается при исчерпании здоровья или достижении предельного возраста; итог зависит от накопленной жизни.

## Сохранения

После каждого решения игра сохраняется в IndexedDB. Ручное сохранение и загрузка доступны в меню. Экспорт JSON создаёт переносимую резервную копию, импорт проверяет структуру и игровые ограничения. Данные привязаны к браузеру и домену; перед очисткой браузера или сменой адреса экспортируйте JSON. Звук и анимации настраиваются отдельно. Сброс удаляет локальную жизнь только после подтверждения.

## Render: бесплатный Static Site

В корне репозитория есть `render.human-exe.yaml`, внутри игры — `render.yaml`. Они создают только Static Site, без платного сервера и базы данных. Существующий корневой Blueprint Python-приложения сохранён.

Самый короткий путь: Render → New → Static Site → подключить этот репозиторий → выбрать ветку с HUMAN.EXE → Root Directory: `human-exe` → Build Command: `npm ci && npm run build` → Publish Directory: `dist`. Static Site использует бесплатное размещение. Для Blueprint укажите `render.human-exe.yaml` в поле Blueprint Path. После слияния PR выберите основную ветку, чтобы обновления публиковались автоматически. Секреты и переменные окружения не нужны.

Сайт не считается опубликованным до успешного развёртывания в вашем Render. Все игровые данные остаются в браузере игрока.

## Архитектура

- `src/game.ts`, `types.ts`: чистый детерминированный движок и типы.
- `src/events.ts`: авторские события и связи между решениями.
- `src/catalogs.ts`: профессии, имущество, достижения и концовки.
- `src/store.ts`: Zustand, действия и последовательное автосохранение.
- `src/persistence.ts`: IndexedDB и проверяемый импорт.
- `src/App.tsx`, `styles.css`: адаптивный игровой интерфейс.
- `src/*.test.ts`: автоматические проверки.

Первый релиз содержит 204 уникальных события: 120 основных, 13 детских, 30 глав десяти сюжетных цепочек, 33 события профессий и имущества и 8 взрослых сатирических сцен. Работают 22 профессии, 11 объектов, 50 достижений и 20 концовок. Тысяча событий — цель дальнейшего развития, а не заявленная функциональность этой версии. Контент не создаётся заменой имён в одном шаблоне.

## Репозиторий

Игра находится в отдельной папке, чтобы не затронуть ранее существовавший VOLTRIX. Его Python-код и конфигурация сохранены. CI игры независимо выполняет npm-тесты и сборку.

## Проверка интерфейса

```sh
npm run dev
# В другом терминале:
npx playwright install chromium
npm run test:browser
```

Для уже установленного Chromium: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`. Для production-проверки используйте `TEST_URL=http://localhost:4173` и запущенный `npm run preview`. Браузерная проверка проходит рождение, выбор, все разделы, обновление страницы, ручное сохранение, экспорт/импорт и мобильный экран.
